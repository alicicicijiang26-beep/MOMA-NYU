# MOMA-NYU
MOMA WAYFINDING
 
Developed during an NYU summer research program focused on The Museum of Modern Art (MoMA), this augmented reality navigation app addresses wayfinding challenges for museum visitors, particularly international tourists and first-time guests. The application streamlines navigation by detecting the user's current floor, identifying nearby amenities—such as restrooms, accessible facilities, water fountains, and dining spaces—and generating interactive 3D directions directly over the physical environment using live AR simulation.

Features
Floor-Aware Location Detection: Prompts users to specify their current floor to filter and pinpoint the closest available amenities in real time.

Comprehensive Amenity Routing: Maps precise destinations for essential services including standard restrooms, wheelchair-accessible restrooms, water fountains, cafes, and dining halls.

Live 3D Augmented Reality Navigation: Launches an interactive, real-world 3D camera view that visually overlays directional cues to guide visitors straight to their target destination upon confirmation.
